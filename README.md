RPG Cyberpunk

RPG de texto desenvolvido em Python ambientado em um universo cyberpunk repleto de megacorporações, implantes cibernéticos e conflitos urbanos. O jogador assume o papel de um personagem perdido em uma cidade dominada por tecnologia e conflitos que talvez não pertencem a ele.

 Sobre o projeto

Cyberpunk-RPG é um jogo executado diretamente no terminal do Python, com foco em:

* Progressão de personagem
* Sistema de combate
* Inventário
* Narrativa baseada em texto

O projeto foi desenvolvido para praticar lógica de programação e conceitos de desenvolvimento de jogos utilizando Python.

Tecnologias utilizadas

* Python 3
* Programação orientada a objetos
* Bibliotecas nativas do Python

Como executar

Clone o repositório: https://github.com/marioassis07/Cyberpunk-RPG.git

Entre na pasta: cd Cyberpunk-RPG

Execute o jogo: python main.py ou o executável Cyberpunk RPG.TXT V1.0.exe

Como jogar

Ao iniciar:

1. Digite o nome do personagem
2. Inicie sua jornada
3. Use os comandos usando somente os números de 1 a 5
4. Derrote inimigos
5. Morra muitas vezes
6. Ganhe experiência e recursos
